# 定了什么

> 一条一个决定。**原因比结论重要**——三个月后你只会记得结论，忘了为什么。

## 格式

```markdown
## 2026-01-01 - 一句话

- **定了什么**：
- **为什么**：
- **谁定的**：
- **影响 / 边界**：
- **后来**：（可选：被哪条取代）
```

## 被推翻的决定

**不要删。** 在原条目下面补一行：

```markdown
- **后来**：2026-04-01 被「改用 X」取代，原因是……
```

删掉它等于删掉「当时为什么那么想」，下次还会踩同一个坑。
