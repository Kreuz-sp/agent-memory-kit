# assets/

Raw files go here: screenshots, PDFs, audio, video.

## Rules

- **Text is the memory; files here are evidence.** Write down what a file says or shows — a file alone won't be read.
- Reference a file from an entry by relative path, e.g. `assets/2026-03-12-error.png`.
- This folder is skipped by the index. Nothing here is searchable by `build_index.py`.
- Keep the library small: large files belong outside git (external storage, or Git LFS).
- Never put secrets, tokens, or private documents here.
